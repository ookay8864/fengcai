# 蜂采 v0.10.1（測試版）

碰一下 NFC 吊飾就打卡，把每趟旅行收成一個「旅行包」。

- 大人頁面：`index.html`，打卡、補照片影片和聲音、採蜜地圖、旅行包、設定與備份
- 兒童頁面：`kid.html`，小小打卡官：蓋章、說一句話、花園地圖、我的章本

## v0.10.1 修改

## 二、放上網路（GitHub Pages，免費）

1. 登入 GitHub，右上角「+」→ **New repository**
   - Repository name：`fengcai`
   - 選 **Public**（免費帳號要公開才能用 Pages；公開的只有程式碼，你的照片和打卡資料都在手機上，不會上傳）
   - 按 **Create repository**
2. 在新倉庫頁面按 **uploading an existing file**
3. 把解壓縮後 `fengcai` 資料夾**裡面**的所有檔案和資料夾（`index.html`、`kid.html`、`css`、`js`、`assets`、`README.md`）一起拖進去，按 **Commit changes**
4. 進入倉庫的 **Settings → Pages**
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**，資料夾選 **/(root)**，按 **Save**
5. 等 1–3 分鐘，頁面上方會出現網址：
   `https://你的帳號.github.io/fengcai/`

> 在中國大陸，github.io 通常打得開，但速度不一定穩定。之後正式使用時，可以搬到國內的主機（需要 ICP 備案）。

## 三、在 iPhone 上試用（吊飾還沒到也可以）

1. 用 **Safari** 打開上面的網址
2. 點下方「設定」→ 打開 **模擬模式**
3. 回到「打卡」按大六角形按鈕，就會用雲南的示範地點走一次完整流程
4. 第一次會詢問「定位」和「麥克風」權限，請選**允許**
5. 試完後到「設定」把模擬模式關掉，就會用真實定位

**提醒：測試期請一律用 Safari 開啟**，不要「加到主畫面」。因為 NFC 感應打開的是 Safari，而主畫面的網頁 App 和 Safari 是兩份分開的資料。

## 四、寫入 NFC 吊飾

1. 淘寶搜尋「**NTAG215 NFC 鑰匙扣**」，買 3–5 個（多的拿來測試）
2. iPhone 安裝免費 App「**NFC Tools**」
3. 打開蜂采「設定」→「NFC 吊飾網址」，複製**大人吊飾**的網址
4. NFC Tools → **寫入** → **新增記錄** → **網址/URI** → 貼上網址 → **確定** → **寫入（Write）** → 把吊飾靠近 iPhone 頂端
5. 換一個吊飾，用同樣方法寫入**孩子吊飾**的網址
6. 測試：螢幕解鎖狀態下，吊飾碰 iPhone 頂端 → 跳出通知 → 點開

建議在兩個吊飾上貼不同顏色的貼紙，方便分辨大人和孩子的。

## 五、設定高德地圖（顯示「附近地點」清單）

沒有設定也能用，只是要自己輸入地點名稱。設定後會自動列出附近的餐廳和景點。

1. 到 **lbs.amap.com**（高德開放平台）註冊並完成個人開發者認證
2. 控制台 → **應用管理 → 我的應用 → 創建新應用**
3. 在應用下按 **添加 Key**，服務平台選 **Web端（JS API）**
4. 建立後會得到 **Key** 和 **安全密鑰**
5. 打開蜂采「設定」→「高德地圖」，貼上兩組文字 → 儲存 → 重新整理頁面

> 個人自用通常在免費額度內。安全密鑰目前存在你手機上；之後正式上線時，會改成由伺服器代為保管。

## 七、目前的限制（v0.1）

- 資料只存在這支 iPhone 的 Safari 裡：清除網站資料或很久沒打開，可能被系統清掉，**每趟旅行後請匯出備份**
- 換手機或和家人共用，要等雲端版本
- 一鍵短片在 iPhone Safari 上尚未實機測試；影片片段目前不含原本的聲音（只用錄音和背景音樂）
- 明信片上的地圖目前用插畫版（即使有高德金鑰），因為真實地圖圖磚無法直接存成圖片
- 沒有高德金鑰時，地圖是插畫示意圖，花的相對位置是真的，但沒有街道
- 真實地圖（高德）版本在這次測試環境中無法連線驗證，填入金鑰後請實測一次
- 兒童花園地圖目前一律是插畫版（不需要金鑰）
